# The en→es dictionary tables

The reduced tables Cymbra Lingua's English→Spanish data pack is built from: English glossed in
Spanish, for Spanish speakers studying English (add-lingua-pack-en-es, change 22 of
`docs/lingua/language-matrix-programme.md`). This folder holds the native side alone; English's own
tables are in `../en/`, written by en-fr's reduction.

No tables yet: en-es's first `lingua-pack-update` dispatch, on the change's branch, publishes the
files it derives from the Spanish Wiktionary's dump and the English Wiktionary's English extract
under `lingua-pack-sources-en-es-<snapshot>`; the pinned reduction that follows commits the tables
here with their pin, and this file then describes them.
