# Tasks

**How this change is implemented** (the programme's process for a reduction): the implementing agent
pushes its work to a branch `impl/refine-lingua-it-es-glosses` and opens no pull request; the
programme's coordinator dispatches the reduction on that branch (task 3.1), and the workflow pushes the
reduced tables, the re-blessed golden and the re-blessed card to its own side branch,
`lingua-pack/it-es/<snapshot>-reduce`; every commit after the dispatch (tasks 3.2–5.4) goes on that side
branch; the pull request opens from it only once tasks 5.1–5.3 are green, and merges once the owner
approves the gloss diff, after a specialist's review (task 4.1).
