Contexte instrument — modale de choix et sélecteur permanent

Le déclencheur est « la première fois que la batterie est visible pour cette installation » — après connexion pendant la bêta, dès le premier lancement une fois la feature généralisée. Même règle, moment différent, aucun cas particulier à coder pour la transition.

① La modale, une seule fois

Formulée comme un choix, jamais comme une récompense : « tu as débloqué la batterie » n'aurait aucun sens pour un nouvel utilisateur d'après-généralisation, pour qui elle a toujours été là.

② Le sélecteur, permanent en tête d'accueil

Pas dans les réglages. C'est ce qui répond à « sans que l'utilisateur se demande comment » : il n'a pas à s'en souvenir, il le voit.

Le sélecteur n'apparaît que si la batterie est visible. Pour tout le monde d'autre — aujourd'hui, l'immense majorité — l'accueil est exactement celui d'aujourd'hui, sans contrôle nouveau et sans question posée. Il n'y a rien à choisir quand il n'y a qu'un choix.

③ Ce que le contexte pilote — et ce qu'il ne pilote pas

Le contexte est collant : il ne change que si l'utilisateur le change. Ouvrir une partition ne le modifie jamais.

Trois cas limites à traiter : jamais choisi → défaut piano ; campagne fermée sans élargissement du scope → repli silencieux sur piano, sinon l'utilisateur se retrouve devant un accueil vide sans explication ; contexte batterie mais aucune partition de batterie → une invitation explicite à basculer, jamais un écran vide muet.
