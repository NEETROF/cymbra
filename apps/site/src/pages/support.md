Une question sur Cymbra Music, un problème avec votre compte ou votre abonnement ?
Écrivez-nous : chaque message reçoit une réponse.

## Nous contacter

**[contact@cymbra.app](mailto:contact@cymbra.app)**

Pour que nous puissions vous aider rapidement, précisez si possible :

- l'appareil et son système (par exemple *iPad, iPadOS 26* ou *Mac, macOS 26*) ;
- la version de l'app ;
- ce que vous faisiez, et ce qui s'est passé.

## Questions fréquentes

### Mon abonnement

Un abonnement se gère depuis la boutique qui l'a encaissé :

- **App Store** : Réglages → votre nom → *Abonnements* ;
- **Google Play** : Play Store → votre profil → *Paiements et abonnements* ;
- **achat sur le web** : [Mon compte](/account).

Après un changement d'appareil, ouvrez *Abonnement* dans l'app et touchez
*Restaurer les achats*.

### Mon compte

- **Mot de passe oublié** : sur l'écran de connexion, touchez *Mot de passe oublié ?*
- **Supprimer mon compte** : dans l'app (menu du compte → *Supprimer le compte*), ou
  [depuis le site](/suppression-compte).

### Mes données

Ce que nous collectons et pourquoi : [politique de confidentialité](/confidentialite).
Pour toute demande concernant vos données : [privacy@cymbra.app](mailto:privacy@cymbra.app).
